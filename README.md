# 质管办奖罚通知生成器

医院质管办月度奖罚通知Excel生成工具。

## 功能

- 上传源文件自动生成奖罚通知Excel
- 支持病历乙级罚款计算
- 支持优秀病历奖励
- 支持迟交病历扣罚
- 支持质控医生奖励和不良事件奖励
- 适用于A4纸打印

## 规则说明

| 项目 | 金额 | 说明 |
|------|------|------|
| 门诊乙级 | 100元/份 | 评级为乙级的门诊病历 |
| 环节乙级 | 100元/份 | 评级为乙级的环节病历 |
| 终末乙级 | 200元/份 | 评级为乙级的终末病历 |
| 优秀病历奖励 | 300元/份 | 第n列标注为"优秀"的甲级病历 |
| 迟交病历 | 按实际罚款 | 来自迟交汇总表 |
| 质控医生奖励 | 200元/人 | 来自医疗质量安全管理通报 |
| 不良事件上报 | 30元/例 | 来自医疗质量安全管理通报 |

## 使用方法

### 1. 安装依赖

```bash
pip install flask openpyxl python-docx
```

### 2. 运行服务

```bash
python app.py
```

### 3. 访问页面

浏览器打开 http://localhost:5000

### 4. 上传源文件

需要上传3个源文件：

1. **全院质控汇总.xlsx** - 包含门诊/住院病历评级
2. **出院病历迟交汇总表.xlsx** - 迟交病历罚款明细
3. **医疗质量安全管理通报.docx** - 质控医生奖励和不良事件奖励

### 5. 下载生成文件

点击"生成奖罚通知"按钮下载Excel文件。

## 输出文件

生成的Excel包含两个Sheet：

### Sheet1
- （一）病历奖惩 - 34个科室的门诊/住院/迟交扣罚和优秀奖励
- （二）质控医生奖励 - 人员明细
- （三）不良事件主动上报奖励 - 人员明细
- （四）单病种上报奖励
- 其他 - 本月奖励/处罚合计、制表人、审核人、领导意见

### Sheet2
- 49个科室汇总表（包含社康）
- 包含病历扣罚、优秀奖励、质控医生奖励、不良事件奖励、单病种奖励
